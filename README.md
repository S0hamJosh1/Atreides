# Atreides

Atreides is a maritime digital twin and sensor intelligence platform concept site built with Next.js 16.

## Product direction

The platform is designed to help vessel operators and insurers reduce preventable failures, improve maintenance timing, and create a live operational picture of each ship without invasive system integration.

Core ideas:

- Non-intrusive sensor deployment
- Real-time vessel telemetry
- External data fusion with AIS and weather context
- A live digital twin of ship health and behavior
- Predictive analytics for failure prevention and efficiency

## Local development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

## Stack

- Next.js 16 App Router
- React 19
- Custom CSS
- Local `@fontsource` packages for Space Grotesk and Manrope
